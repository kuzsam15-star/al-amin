# Статический контент AL-AMIN

`site.json` содержит тексты сайта, а `specialists.json` — единственный публичный каталог.

Данные специалиста появляются в сборке только при `published: true`. Контакты публикуются только при явном заполнении соответствующих полей владельцем каталога. Отсутствующие необязательные данные не создают пустых секций.

Для редактирования без ручной работы с JSON используется локальный owner editor:

```text
pnpm owner:editor
```

Он доступен только на `127.0.0.1`, не входит в `out/` и не выполняет Git-команды автоматически.
