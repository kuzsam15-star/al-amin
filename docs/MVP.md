# Граница текущего продукта

В продукт входят Home, каталог, публичные профили, прямые контакты, информационные страницы и локальный owner editor.

Не входят: аккаунты, регистрация специалистов, заявки, кабинет, модерационная панель, отзывы от посетителей, жалобы, CRM, чат, платежи, Auth, SMTP и production backend.
