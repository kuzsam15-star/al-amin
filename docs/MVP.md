# Граница MVP

В первую версию входят поиск и просмотр опубликованных профилей, ручная модерация заявок, публикация профиля, текстовые отзывы и жалобы. Платформа не принимает оплату и не разрешает частные споры.

Публичный посетитель не обязан создавать аккаунт. Доступ к административной части предоставляется только пользователю Supabase Auth, записанному в таблицу `moderators`.
