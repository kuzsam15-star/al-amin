# Идеи для будущих этапов

## AI-помощник администратора

Отдельный будущий этап: помощник для SEO-аудита, предложений по заголовкам и обновлению публичных страниц, а также периодической проверки сайта. Не является частью текущей админ-панели и не должен получать право самостоятельно публиковать изменения.
