# Архитектура AL-AMIN

## Схема

```
Браузер
  └─ Next.js App Router
       ├─ публичный каталог и профиль
       ├─ кабинет специалиста и админка
       ├─ server actions / API routes
       └─ Supabase: Auth, PostgreSQL, Storage
```

## Роли

- Гость: видит только опубликованные профили, публичные отзывы и активные значки доверия.
- Специалист: создаёт заявку, ведёт собственный черновик/ревизию, видит свой кабинет.
- Модератор: рассматривает заявки и ревизии, видит материалы на модерации.
- Администратор: управляет модерацией, скрытием профилей, значками и удалением ошибочных записей.

## Основные процессы

1. Регистрация и вход: Auth создаёт пользователя, кабинет связывается с `owner_id`.
2. Заявка: специалист создаёт одну заявку и загружает медиа.
3. Модерация: решение публикует профиль либо возвращает заявку на доработку.
4. Ревизия: опубликованный профиль не меняется напрямую; новая версия ждёт решения модератора.
5. Публикация: одобренная ревизия атомарно обновляет существующий профиль без дубля.
6. Каталог: показывает только профили со статусом `published`.

## Ключевые данные

- `applications` — заявки;
- `specialists` — опубликованная версия профиля;
- `specialist_revisions` — ожидающие изменения;
- `moderators`, `account_profiles`, `audit_log` — доступ и аудит;
- `reviews`, `trust_badges`, `specialist_trust_badges` — публичное доверие;
- `profile-media` — фотографии заявок, ревизий и профилей.

## Границы безопасности

- Права проверяются на сервере и в RLS.
- Публичная выдача ограничена опубликованными данными.
- Модераторские заметки и контакты авторов отзывов не входят в публичную модель.
- Медиа выдаются через контролируемый маршрут, а не прямой URL Storage.

## Главная страница и CMS

- `/` — каноническая Civic Home; параллельная старая Home больше не рендерится.
- `/design-preview` перенаправляет на `/` и не является отдельным источником UI или данных.
- Структура Home и дизайн-система закреплены в Civic React-компонентах; Admin изменяет только валидируемые текстовые значения `site_content`.
- Существующие CMS-данные сохранены и сопоставлены действующим полям Civic Home и информационных страниц.
- Logout перенаправляет на `/` и не управляет выбором визуального шаблона.
