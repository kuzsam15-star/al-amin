# Как добавить специалиста из файла заявки

1. Отправьте кандидату ссылку на публичную страницу `/apply/`.
2. Кандидат заполняет анкету, выбирает фотографию и нажимает «Скачать заявку».
3. Получите от кандидата один файл `.alamin` или `.alamin.json` через выбранный вами мессенджер или email.
4. Запустите Owner Editor командой `pnpm owner:editor` и откройте локальный адрес, который он покажет.
5. Перейдите в «Заявки» → «Импортировать заявку» либо перетащите файл в область импорта.
6. Проверьте данные, контакты, прямоугольное фото профиля и круглый аватар. Оба кадра можно независимо поправить перетаскиванием и масштабированием.
7. Отметьте только те данные, которые действительно разрешено показывать публично, и нажмите «Одобрить и добавить в каталог».
8. Откройте предложенный локальный профиль и проверьте результат.
9. Отдельно выполните commit/push/deployment только после просмотра diff и статической сборки.

## Важно

- Импорт означает «сохранено локально», а не «доступно посетителям в интернете».
- Одобрение означает «добавлено в локальный каталог», а не «опубликовано в интернете».
- Файл кандидата недоверенный: не открывайте его в редакторе текста и не переносите данные вручную; используйте импорт Owner Editor.
- Повторный импорт того же файла откроет существующую заявку. Изменённый файл с тем же ID даст конфликт и ничего не перезапишет.
- Оригинал хранится только в `.local-editor/submissions/`. В Git и `out/` попадают только одобренные JSON-данные и два оптимизированных WebP.
- Не добавляйте `.alamin`, `.alamin.json` или `.local-editor/` в Git вручную.
