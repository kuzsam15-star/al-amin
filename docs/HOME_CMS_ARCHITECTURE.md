# Home CMS и Civic Home

## Источник истины

- `/` — единственная пользовательская главная и рендерит `CivicHome`.
- `/design-preview` — технический alias, который перенаправляет на `/`; отдельного дерева Home у него нет.
- Figma и Civic React-компоненты определяют структуру, сетку, компоненты, цвета, типографику, spacing, breakpoints и Cover Flow.
- `public.site_content` определяет только текстовые значения. CMS не принимает HTML, CSS или JavaScript.

## Поля CMS

| Поле | Где используется | Ограничение |
|---|---|---:|
| `brand_name` | логотип, footer, метаданные | 40 |
| `tagline` | eyebrow первого экрана Civic Home | 72 |
| `hero_title` | главный заголовок Civic Home | 96 |
| `hero_text` | описание первого экрана Civic Home | 360 |
| `contact_email` | поддержка и запросы по данным | 320 |
| `seo_title` | metadata и Open Graph | 160 |
| `seo_description` | metadata и Open Graph | 320 |
| `about_text` | `/about` | 5000 |
| `rules_intro` | `/rules` | 5000 |
| `privacy_text` | `/privacy` | 5000 |

CTA, порядок секций, Trust System и Cover Flow не редактируются через CMS. Их изменение является отдельной дизайн- и продуктовой задачей.

## Сохранение и совместимость

- Admin обновляет только перечисленные колонки одной строки `site_content`.
- Валидация выполняется в HTML-форме и повторно в server action; слишком длинные значения не обрезаются молча, а отклоняются.
- После сохранения инвалидируются `/` и соответствующие информационные страницы.
- Существующие значения базы подключены к Civic Home без удаления или автоматической перезаписи.
- Неиспользуемых legacy-полей в текущей строке `site_content` нет: все существующие поля сопоставлены действующим страницам.
- Изменение схемы Supabase для этой архитектуры не требуется.

## Auth и logout

Logout завершает Supabase-сессию и перенаправляет на `/`. Поскольку `/` является канонической Civic Home, выход больше не возвращает старый шаблон и не зависит от preview-cookie.
