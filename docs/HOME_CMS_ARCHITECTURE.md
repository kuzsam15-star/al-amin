# Home content architecture

Прежняя Supabase CMS больше не является runtime-источником.

- Структуру и Civic Precision UI задают React-компоненты.
- Тексты Home и информационных страниц хранятся в content/site.json.
- Специалисты Cover Flow берутся только из опубликованных статических записей.
- При отсутствии реальных записей показывается честное пустое состояние.
- Owner editor изменяет специалистов локально; публичной CMS/admin route нет.

Любое изменение content проходит единый validator до build. HTML, script и управляющие bidi-символы в текстовых полях запрещены.
