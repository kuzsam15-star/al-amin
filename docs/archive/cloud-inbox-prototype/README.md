# Архив решения: облачный inbox заявок

Статус: **отклонено и неактивно**. Зафиксировано 26 сентября 2026 года.

Ранее для AL-AMIN был подготовлен, но не применён прототип:

- таблица `catalog_submissions`;
- приватный Storage bucket;
- Edge Function;
- Turnstile и облачный rate limiter.

Прототип не применялся к Supabase и не разворачивался. Его активные migration/function/config-файлы удалены из рабочих путей, чтобы их нельзя было случайно выполнить стандартными командами Supabase.

Окончательное решение проекта:

`/apply` → локальный файл `.alamin` → ручная передача владельцу → локальный Owner Editor → ручная проверка → статический каталог.

Для заявок Supabase, Edge Functions, Turnstile, SMTP и облачный inbox не используются. Возвращать этот прототип в активные пути или разворачивать его автоматически запрещено без отдельного нового архитектурного решения владельца.

Локальная recovery-копия состояния до перехода сохранена в игнорируемой папке `outputs/` и не предназначена для публикации.
