# Дорожная карта

## Завершено в MVP

Публичный каталог, заявки, вход модератора, жизненный цикл заявок и профилей, отзывы, жалобы, аудит, RLS и базовый Storage-бакет для аватаров.

## До тестового запуска

1. Подключить настоящий Supabase-проект и назначить администратора.
2. Заменить демонстрационные данные реальными, получив согласие участников.
3. Настроить SMTP-письма о статусах заявок и подтверждение контактов.
4. Добавить сквозные Playwright-сценарии к развёрнутому стенду.

## Следующие версии

Защищённая ссылка владельцу профиля, подтверждение реального взаимодействия для отзывов, многоязычность и понятная процедура апелляции.
