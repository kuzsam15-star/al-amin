# Дорожная карта

## Перед публикацией

1. Владелец подтверждает реальные профили, разрешённые публичные контакты и факты проверки.
2. Фотографии переносятся в static assets и оптимизируются owner editor.
3. Проверяются Home, Catalog и каждый Public Profile на desktop/mobile.
4. Выбирается production static host и подключается custom domain.
5. Deployment включается только отдельным решением владельца.

## Позже

Многоязычность, дополнительные SEO landing pages и аналитика рассматриваются отдельно. Они не должны возвращать пользовательскую платформу или backend без нового продуктового решения.
